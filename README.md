# Kate Reed Portfolio

A simple, responsive personal portfolio site. It does not need a build step: open `index.html` with the VS Code **Live Server** extension or double-click it to preview locally.

## Edit it

- Your introduction and skills: `index.html`
- Project cards: the section beginning with `id="projects"`
- Colors, typography, and layout: `styles.css`
- GitHub profile is already linked to `https://github.com/katereed2`

## Run in VS Code

1. Open the `kate-portfolio` folder in VS Code.
2. Install the free **Live Server** extension by Ritwick Dey.
3. Right-click `index.html` and choose **Open with Live Server**.

## Publish with GitHub Pages

1. Create a new GitHub repository named `katereed2.github.io`.
2. Upload the contents of this folder (not the folder itself) to the repository.
3. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. Your site will appear at `https://katereed2.github.io` within a few minutes.
