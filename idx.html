01 / THE PROJECT

Learning the complete product flow.

The project was structured as a week-by-week software engineering experience. I worked through the path from setting up a local database to connecting it to a backend API and then displaying searchable property data in a frontend interface.

  • Set up a MySQL property database in a Docker development environment.
  • Worked with REST API routes for listings, filters, property details, and open-house information.
  • Built React interface pieces for search results, filters, pagination, and property-detail views.
  • Practiced validation, error handling, testing, documentation, and Git-based development.

02 / ARCHITECTURE

Three layers, one experience.

The frontend never connects directly to the database. React sends requests to the Express API, which validates the request, queries MySQL, and returns the property data needed by the interface.
